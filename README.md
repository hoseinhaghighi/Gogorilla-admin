# Gogorilla Admin 1.0

پنل اندرویدی مدیریت WooCommerce برای Gogorilla، با رابط فارسی و RTL.

## امکانات
- ورود و ذخیره اتصال WooCommerce
- داشبورد مدیریت
- فهرست محصولات تا 100 مورد
- افزودن محصول
- ویرایش محصول
- حذف محصول
- قیمت عادی و تخفیف
- موجودی و SKU
- لینک تصویر محصول
- فهرست سفارش‌ها
- تغییر وضعیت سفارش
- تنظیمات و خروج
- رابط مشکی با رنگ #F8BE39

## ساخت APK بدون Android Studio
این پروژه Workflow گیت‌هاب دارد. بعد از قرار دادن پروژه در یک repository و Push کردن، GitHub Actions با Android/Gradle محیط خودش APK را می‌سازد و در Artifacts قرار می‌دهد.

Workflow: `.github/workflows/android.yml`

## نکته امنیتی
کلیدهای WooCommerce داخل APK برای انتشار عمومی مناسب نیستند. این نسخه برای پنل شخصی/آزمایشی طراحی شده است. برای انتشار گسترده، معماری امن با backend/token exchange توصیه می‌شود.
